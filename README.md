# Chandra Adam Pratama — Portfolio

Personal portfolio showcasing selected projects, professional experience, and my work as a full-stack developer.

**Live portfolio:** [ythchandraap.github.io](https://ythchandraap.github.io)

## Built with

- Next.js
- React and TypeScript
- Tailwind CSS
- React Icons and Lucide

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

For a production build, run `npm run build`. The static site is generated in `out/`.
